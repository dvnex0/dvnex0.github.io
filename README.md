# DVNex — Site Oficial v2

Site estático de lançamento do DVNex.

## Publicar no GitHub Pages
1. Crie um repositório para o site.
2. Envie `index.html`, `style.css` e `script.js` para a raiz.
3. Abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha `main` e `/ (root)`.
6. Salve.

O site aponta os downloads para a release oficial:
https://github.com/DVTech0/DVNex/releases/tag/Browser

## Logo
O arquivo `dvnex-logo.png` é o logo oficial usado no site.
